request (November 2026). These are Gulf Coast Palms' own job photos and ad video.

They were saved from the screen, not downloaded as original files, so they are a little
smaller than the originals. If the original camera files turn up, drop them in here under
the same names and run `node scripts/build-redesign-media.mjs`.
